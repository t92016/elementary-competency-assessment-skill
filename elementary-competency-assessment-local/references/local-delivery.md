# 本機 Word 與 PDF 交付

## 固定母稿與四份產物

以老師確認的同版母稿固定題數、順序、情境、圖表、題幹、選項、配分、答案與詳解，不在匯出時重新命題。每次正式交付：

- 學生卷.docx
- 學生卷.pdf
- 教師卷.docx
- 教師卷.pdf

檔名加單元與試題版次，輸出放在工作目錄內新的分次資料夾。學生卷只含正式題目、材料與作答區；教師卷完整收錄學生卷，另附全部答案詳解、評分規準、藍圖及來源查讀狀態。不能用「詳見學生卷」「其餘同上」省略。

## 產生與轉換

先讀 [母稿格式](assessment-data.md)，以同一份結構化母稿寫兩卷。可用 [build_assessment.py](../scripts/build_assessment.py)：

~~~text
python <技能路徑>/scripts/build_assessment.py <母稿.json> --output <新的輸出資料夾> --pdf-engine word
~~~

一般 A4、黑字、繁體中文相容字型；依年級配置字級和作答空間。可用 --font 指定已安裝中文字型，預設 Microsoft JhengHei。一般圖表可用表格／本機圖片；圖說與單位要完整。數學式和注音有額外需求時換用合適工具，不改題意或省圖。

先產 DOCX，再由同一 DOCX 轉 PDF；不另行重打一份內容不同的 PDF。禁止改副檔名冒充轉檔。Google Docs 僅為老師另有需求、連線與權限已具備時的選項，不依賴 Gemini 匯出按鈕或 Canvas。

## 逐題與版面驗收

1. 回讀學生卷／教師卷 DOCX 及 PDF，逐題比對母稿，確認全部材料、題幹、選項、配分、答案、詳解、規準與附錄末尾。
2. 單選 A～D 各有解析，簡答有參考答案、分項分數與部分給分例。藍圖每小題一列，配分合計與卷首一致。
3. 學生卷不得含教師答案、藍圖、查讀報告或執行說明。檢查圖片及題幹本身是否不慎洩答，不能只靠程式欄位分離。
4. 渲染兩卷所有頁面並實際查看 PNG，確認繁體中文無亂碼、無缺字、裁切、重疊、漏圖或不合理跨頁，簡答留足空間。DOCX 的 PDF 渲染亦作為版面預覽；其他 Word 軟體開啟仍可能有差異。
5. QA.json 是自動結構／文字檢查，不能取代語意、圖片或視覺核對。另寫 QA-review.md 記錄實際看的頁碼、內容與版面結論、問題及修正。

只看工具成功提示、字數或首中末抽查不合格。PDF 文字抽取受字型與換行影響時，逐項定位差異並核對頁面，不直接忽略所有差異。

## 失敗處理與交付

缺套件、轉檔失敗、字型缺失或無法渲染時，保留已完成的母稿及文件，指出哪個步驟未通過。不建立空白檔，不捏造連結，不把僅 DOCX 完成說成四份全過。修正後重新轉檔與檢查。

交付真實本機檔案連結及簡短結果；母稿和 QA 紀錄留在輸出目錄，不混進學生卷。重新出題按 [修訂流程](revision-flow.md)，新舊版分開。
