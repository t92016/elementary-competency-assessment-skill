# 官方查證、命題原則與品質檢核

## 3. 搜尋官方依據
透過目前 Agent 實際可用的搜尋／瀏覽能力查證；Skill 指令本身不會新增上網能力。
優先使用教育部、國教署、國家教育研究院的課綱及命題資料，再使用國教署委託臺師大測驗中心的評量示例。
各科通用命題要素與本輪領域起始入口（仍須依本次科目查讀原文）：
- 自然科學領域課綱發布頁：https://www.naer.edu.tw/PageDoc/Detail?fid=55&id=1290
- 社會領域課綱發布頁：https://www.naer.edu.tw/PageDoc/Detail?fid=55&id=1291
- https://www.naer.edu.tw/upload/1/10/doc/2690/素養導向「紙筆測驗」要素與範例試題.pdf
- https://dpcca.rcpet.edu.tw/Subject_E/SubjectSocial_4.aspx
必須讀到文件正文，不能只憑搜尋摘要、入口標題或自己的記憶聲稱已查證。
建立「機構／文件與年份／實際 URL／查閱日期／正文定位與採用處／讀取狀態」清單。URL 必須是實際來源，不可用「官方網站」「課綱手冊」「教師網分享」等名稱代替。讀取狀態分為已讀正文、僅摘要／目錄、無法讀取、尚未核對；只有第一類可作已查證依據。列出已讀段落的章節、頁序或小節與採用概念，年份無法確認就寫未核對，不猜年份。
檢查適用年級與學習階段，從原始課綱核對學習表現與學習內容代碼；無法核對時先寫能力描述，代碼欄只寫待核對，不列猜測或「預計對應」的代碼。引用前比對代碼、原文內容、學習階段三者，不把另一項內容接到看似熟悉的代碼。
題庫只參考情境、提問和評分方式，原創改寫題目，不複製整題；不可把中學範例說成國小標準。
若搜尋工具不可用或來源讀取失敗，明確說明；可依教材先產出「官方依據待補的草稿」，但不得標為已通過官方檢核。尊重使用者要求必須查證後才命題的限制。官方命題規範用來檢核設計品質，教材／老師確認的目標用來界定考試範圍，兩項都需檢查。教師不用自行整理課綱代碼或官方手冊，由助手搜尋核對；找不到就回報。
優先使用能記錄來源的搜尋／瀏覽工具；必要時可用已授權的連網工具或腳本讀取公開正文，仍須如實記錄 URL、定位與查讀狀態，不假設所有電腦工具相同。
課綱來源先核對封面完整名稱與教育階段，不只看「自然科學領域」字樣；綜合型高中課綱即使附有國小素養表，也不能替代國民中小學學習內容。尚未核對的 URL 不列為已讀來源。

### 3.1 官方 PDF 讀取失敗時
先試可讀的官方網頁正文或附件；仍失敗時，回報具體來源與讀取限制，不把 PDF 搜尋連結當文件直連，不猜年份。若本輪要求「查證後才命題」而尚無可用依據，先停在來源與補件表，不逕自交付正式卷。
本技能附有製作者於 2026-10-10 查讀國教院前述紙筆測驗文件 PDF 第 1～4 頁後的轉述摘要，可作既有參考：問題情境須合理，讓學生運用所學判讀或解決問題；結合學習表現與內容；短題或單題亦可評量素養；避免機械式記憶；紙筆結果不能代表長期實踐或態度。原文發布年份未確認。若採用此摘要，來源表必須寫「技能內既有查讀摘要，非本次連線讀取」，不能寫自己已讀完整官方文件；老師要求本次讀原文時仍須補正文。

## 4. 先做教材摘要與命題藍圖
把教材事實、合理推論、虛構命題情境分開。課文標示「傳說」的內容不得改成確定史實。
列出每題的教材頁碼或公開來源定位、能力目標、必要知識、資料／情境、學生要做的判斷、題型、答案或評分依據、配分與時間估計。
情境必須為比較、判讀、選擇證據、推論、解決問題或說明理由提供作用；避免只加人名與故事包裝背誦題。
5 題只是抽樣，不能宣稱已測量全單元全部目標。時間估計須標為未施測。

## 5. 命題及撰寫詳解
用符合該年級閱讀程度的短句，減少無關資料。
每題都要符合老師確認的教材或公開資料試作範圍。未讀取原課本時，不編造課本頁碼；以來源文件、章節或 PDF 頁序定位，並標明對指定版本吻合程度的限制。自然題的資料、變因、單位、對照條件與科學解釋須互相一致；原創數據要標為示意，不能宣稱實測。若解題必須知道課外資訊，將必要資訊放入題幹，或先取得使用者同意擴大範圍。
單選題只有一個合理的最佳答案；四個選項格式及長度盡量相近，錯誤選項反映可能的迷思，不靠荒謬答案、絕對化字眼或字面長度暗示答案。
題組共享同一材料，各小題盡量能獨立作答；不使上一題答案成為下一題必要條件。
同一題組的小題連續排列，標示共同材料適用題號；不要依題型分章而把獨立題插在題組中間。芹菜染色等示意須明示是否有根及浸水部位；解答只根據材料支持的運送路徑，不把無根切段的結果寫成已證明根的功能。不考組織時，不以維管束、管狀構造的形態作必要知識。
根吸收水分與礦物質，不寫成吸收植物的食物。開放容器水位下降也可能有蒸發，未設對照不可直接當吸收的證明；莖內染色痕跡只能支持水分經過該處，不能據此證明全株每個部位均收到水分。檢查題目是否真正需要材料才能判斷，以及情境中的土栽／水栽、選項用語與答案是否一致。
教師卷每題要有答案、解題步驟、教材依據、各選項為何正確或不適當及常見迷思。
單選詳解逐一列 A、B、C、D，不以「其他皆錯」省略；簡答提供至少一個部分給分例子。將情境改為要做判讀、選擇措施或評估證據的任務，不能只是從敘述中的功能詞找構造名稱。
簡答要有參考答案、可接受的不同表達、分項評分與部分給分示例；配分對應題目明示要求，不臨時增加隱藏要求，不只接受參考答案逐字相同的回答。
涉及不同族群或觀點，使用可追溯的資料，不刻板化、不把所有人的經歷視為相同。紙筆答案只能顯示本題表現，不等同長期態度與實踐能力。

## 6. 自我檢核與修正
逐題檢查：
1. 總題數、題組和題型符合約定，配分合計正確；命題藍圖、題幹、學生卷、教師卷與評分規準的每題配分和總分完全一致。例如 8 題各 8 分加 2 題各 18 分才是 100 分，不得在另一處把簡答寫成 16 分。
2. 年級、內容、歷史時序、單位、圖例、語言及課綱對應正確。
3. 材料提供必要資訊；有推理或應用任務，非純記憶包裝。
4. 單選答案唯一，不會因另一種合理解讀產生兩個答案。
5. 詳解支持答案，簡答評分能與題目要求一一對應。
6. 題組沒有互相洩漏答案，學生卷沒有答案或教師備註。
7. 認知與閱讀負擔符合目標時間；無施測就不宣稱時間已驗證。
發現問題直接修正，再輸出最終同一版本。

### 6.1 交付前的具體核對

在逐題藍圖或QA中，以「學生可見的必要資料 → 要判斷的新主張／方案／關係 → 推理如何支持答案」檢查每一題。若只能寫「圖說直接寫出該名稱」或「照抄材料原句」，該題尚未達本技能要求的推理／應用任務，應重作；不能只將「依據圖文」加進題幹就通過。

學生卷須自足：引用圖1、表2等時，卷內要有該圖／表或足以作答的改寫材料，不能依賴老師另外拿原課本給學生。來源辨識失敗、工具錯誤及製作備註留在教師來源／QA，不放進學生題幹。

總小題數按獨立作答單位計算。簡答可以為同一核心任務訂多個評分面向，但不能把數個互不相關的背誦小問合併計為一題。部分給分例逐項加總，response、各項得分、reason與points必須一致；不能用「約」「教師彈性」掩飾算術矛盾。單選答案位置分散且干擾項合理，不用全同選項作為預設。
